🔹 1. O que é Flexbox

O Flexbox (Flexible Box Layout) organiza itens em uma dimensão: em linha ou em coluna. Ele distribui o espaço livre e alinha os itens sem usar floats ou posicionamento complexo.

Tudo começa no contêiner (elemento pai). Ao aplicar display: flex, os filhos diretos viram itens flex. 

.container {
  display: flex;
}

Eixo principal e eixo transversal

Todo contêiner flex tem dois eixos. O eixo principal é a direção em que os itens são colocados. O eixo transversal é perpendicular a ele.

flex-directionEixo principalEixo transversal
row (padrão)horizontal →vertical ↓
columnvertical ↓horizontal →
💡 Regra de ouro: justify-content trabalha no eixo principal e align-items trabalha no eixo transversal. Se você mudar a direção, os dois trocam de sentido na tela.

2.5 gap

Cria espaço entre os itens, sem precisar de margens. Use gap: 10px (linhas e colunas), ou separe com row-gap e column-gap. 

.container {
  display: flex;
  gap: 10px;            /* igual nos dois sentidos */
  /* gap: 20px 10px;       linha | coluna */
}

2.6 align-content (intermediário)

🧩 3. Propriedades dos itens

Estas propriedades vão nos filhos do contêiner, não no contêiner.

3.1 flex-grow — quanto o item cresce

Define como o espaço livre é dividido. O valor padrão é 0 (não cresce). Aqui, A recebe 1 parte do espaço livre, B recebe 2 partes e C não cresce. 

.a { flex-grow: 1; }
.b { flex-grow: 2; }
/* .c usa o padrão: flex-grow: 0 */
A (grow 1)
B (grow 2)
C (grow 0)

3.2 flex-shrink — quanto o item encolhe

Define como o item encolhe quando falta espaço. O padrão é 1 (pode encolher). Com flex-shrink: 0, o item mantém o tamanho. No exemplo, todos pedem 400px de base; só o A está protegido do encolhimento.

A (shrink 0)
B (shrink 1)
C (shrink 1)

3.3 flex-basis — tamanho inicial

É o tamanho do item antes de crescer ou encolher (no eixo principal). Com flex-direction: row, funciona como a largura inicial.

A forma mais usada: flex: grow shrink basis.

3.6 order — ordem visual

Muda a ordem em que os itens aparecem, sem mexer no HTML. O padrão é 0 e valores menores aparecem primeiro. No HTML a ordem é A, B, C.

⚠️ order altera só o que se vê. Leitores de tela e a tecla Tab seguem a ordem do HTML. Use com cuidado.

🚀 4. Aplicações práticas

4.1 Centralizar um elemento nos dois eixos

O problema clássico, resolvido com duas linhas.

.container {
  display: flex;
  justify-content: center;
  align-items: center;
  height: 160px;
}
Centralizado

4.2 Barra de navegação

A logo fica à esquerda e os links à direita. A margem automática (margin-left: auto) empurra o item para o fim do eixo principal. 

.menu {
  display: flex;
  align-items: center;
  gap: 16px;
}

.menu .ultimo {
  margin-left: auto;   /* ocupa todo o espaço livre antes dele */
}

4.3 Cards que quebram linha sozinhos

Com flex-wrap: wrap e flex: 1 1 180px, cada card tem pelo menos 180px e divide o espaço restante. Reduza a janela e observe as linhas mudarem, sem media query. 

.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 12px;
}

.cards .card {
  flex: 1 1 180px;   /* cresce, encolhe, base de 180px */
}

4.4 Rodapé sempre no fim da página

O próprio style.css deste hub usa esta técnica: o body é uma coluna flex com altura mínima da tela, e o rodapé usa margin-top: auto. 

body {
  min-height: 100vh;
  display: flex;
  flex-direction: column;
}

footer {
  margin-top: auto;   /* empurra o rodapé para baixo */
}
